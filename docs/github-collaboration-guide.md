# GitHub 协作说明

## 每次开始开发前

```bash
git status
git pull origin main
```

确认本地没有未提交的重要修改，再开始写代码。

## 开发过程中

- 一个功能尽量对应一次提交。
- 不要直接修改和当前任务无关的文件。
- 修改云函数后，要提醒其他人重新部署云函数。
- 修改 `app.json` 新增页面后，要让其他人重新编译小程序。

## 提交代码

```bash
git status
git add .
git commit -m "说明本次修改"
git push origin main
```

提交信息建议写清楚，例如：

- `完善管理后台筛选和操作日志`
- `新增学生认证流程`
- `补充上线测试文档`

## 如果别人也改了代码

先执行：

```bash
git pull origin main
```

如果出现冲突，不要随便删除别人的代码。先看冲突文件，再决定保留哪部分。

## 协作注意

- 微信开发者工具登录微信号可以不同。
- AppID 应使用同一个小程序 AppID。
- 云开发权限不要随意给所有人管理员权限。
- 普通协作者通常只需要代码仓库权限。
- 需要部署云函数、管理数据库的人，再单独给云开发权限。
